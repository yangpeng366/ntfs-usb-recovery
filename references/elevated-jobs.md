# 自动提权作业：案例记录

本文是一次实战记录。可复用的通道、脚本与坑位清单在全局 skill `windows-silent-elevate`；本文只记本次发生了什么、哪些结论成立、哪些不成立。

## 场景

当前用户属管理员组，日常窗口带 UAC 过滤令牌；磁盘所有权与设备访问需要已授权的管理员令牌。复用管理员预先注册的计划任务，日常投递不再弹窗。

## 通道与边界

固定任务：运行级别 Highest、交互登录令牌、固定解释器与 dispatcher 路径。dispatcher 读队列中的脚本路径，启动作业，写独立日志，落完成记录。普通窗口只投递并触发。

队列、dispatcher 与作业目录仅限该管理员账户与 SYSTEM 可写；客户端须校验脚本路径落在允许目录内。

**已知缺口**：今日通道只轮询共享完成标记，不能可靠代表子作业退出码；唯一 job ID 与结构化完成记录是加固方向，不是既成事实。

## 本次实战

- 整树继承授权跑了约 22 分钟未结束，主动停止，明确未完成，未称成功。
- 仅授目录自身权限的 icacls 同样长时间不返回（两次）。停止后先确认任务回到 Ready 且原进程退出，再续下一项。
- 最终修好 `F:\found.000`：先备份原 DACL，再用 `GetFileSecurityW`/`SetFileSecurityW` 只给该目录自身加当前用户的非继承允许 ACE，约 0.52 秒完成，不触发后代继承传播。
- 普通用户窗口复验：E 盘 17/17、F 盘 18/18 个非系统一级目录可列举。

## 教训

- 客户端等待超时 ≠ 作业终止。先查任务状态、PID、最后完成项，再定等待或续跑；重投前须确认旧进程已退。
- 日志头 `admin=True` 只证提权成功，非作业成功；须兼看退出码、结束标记与用户视角验收。
- 提权执行的 `.ps1` 一律纯 ASCII：旧 Windows PowerShell 5.1 按系统 ANSI 读无 BOM 文件，中文字面量即成解析错；其 `Clear-Content` 无 `-Encoding` 参数。
- 长作业逐项写开始、结束、耗时、返回码到独立日志；`Out-String` 缓冲到进程结束才见结果，会让日志看着像卡死。
- 提权令牌带 Administrators SID，提权能读不等于用户能读；验收必回普通窗口。
